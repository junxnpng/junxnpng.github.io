저장 위치와 복습 방식

보관함을 고르면 SayMore/카드 안에 저장해요. 카드·다음 복습 날짜·전체 복습 이력은 library.json, 직전 저장본은 library.backup.json에 있어요. notes에는 카드별 옵시디언 노트, media에는 사진·음성이 들어가요.

카드 내용은 이 화면에서 수정하고, 옵시디언 노트 아래의 ‘추가 메모’는 자유롭게 써도 돼요. 폴더 접근이 유지되면 다시 방문할 때 자동으로 읽고, 권한이 만료되면 다시 연결해요. 저장한 카드는 서버로 전송하지 않아요.

복습 간격은 FSRS-6로 계산해요. Anki와 별도의 단어장이며 AnkiWeb과 동기화되지는 않아요. Anki의 추가 화면을 참고했어요.

사진·음성 출처는 각 카드에 남겨주세요. 기본 사진은 Julius Schorzman의 원본(CC BY-SA 2.0), 기본 음성은 Dvortygirl의 녹음을 Wikimedia에서 MP3로 변환한 파일(CC BY-SA 3.0)이에요. 예전 coffee 한 장 예시와 그 폴더의 기록은 그대로 남아 있어요.
