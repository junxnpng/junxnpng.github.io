# Say More 단어 카드

홈의 학습 메뉴 → **첫 100단어 · 카드 만들기와 복습**으로 들어갑니다. **Dropbox 연결**로 아이폰과 맥에서 같은 카드와 기록을 사용할 수 있습니다. 맥 Chrome 또는 Edge의 **저장 설정 → 폴더 연결**로 로컬 보관함을 사용할 수도 있습니다.

1. **카드 추가**에서 종류와 덱 이름을 정합니다.
2. 그림 → 단어는 사진과 정답, 앞면 → 뒷면은 질문 또는 사진과 정답을 넣습니다. IPA·MP3·예문·나의 기억·태그는 선택입니다. 녹음(MP3)과 합성 음성 문구가 둘 다 있는 카드는 뒷면에 ‘사람 녹음’과 ‘기기 합성 음성’ 버튼이 나란히 나옵니다. 정답이 영어 단어나 짧은 표현이면 뒷면에 Cambridge 사전(미국식)의 해당 항목으로 가는 링크도 붙습니다. 녹음이 없는 카드는 그 페이지의 US 스피커로 사전 음성을 들을 수 있습니다.
3. **추가하고 다음 카드**로 계속 만들거나 **저장하고 목록 보기**로 확인합니다. ⌘Enter도 저장합니다.
4. **복습하기**에서 IPA 전체·세부 항목, 기초 단어 100장 묶음, 또는 내 덱을 선택합니다. **예정된 복습**에서 정답을 확인하고 모름·어려움·알맞음·쉬움 중 하나를 고릅니다. 다음 날짜와 전체 기록이 파일에 저장됩니다. Space는 정답, 숫자 1–4는 답변입니다. 예정된 복습은 한 번도 안 한 카드를 보관함 순서대로 먼저 보여주고, 그다음 복습 날짜가 된 카드를 마지막으로 답한 지 가장 오래된 것부터 보여줍니다. 복습한 적이 있는 카드는 예정일에서 얼마나 지났는지를 카드 목록·복습 화면·복습 이력·읽기용 노트에 표시합니다. 이 값은 따로 저장하지 않고 복습 이력(답한 시각과 그때의 예정일)에서 계산합니다.
5. **모름 다시 보기**는 선택한 묶음의 모름 카드를 원할 때 꺼내는 기능입니다. 한 번 시작한 묶음에서는 각 카드를 한 번씩만 보여줍니다. 답을 떠올리면 모름 목록에서 빠지고, 계속 모름이면 다음에 다시 꺼내볼 수 있습니다. 마지막 모름 평가에서 24시간이 지나면 일반 복습에도 포함됩니다.

**카드 목록**의 ‘목록 순서’에서 기본 순서, 만든 날짜(최근·오래된 순), 마지막 복습(최근·오래된 순), 복습 예정일 순으로 정렬할 수 있습니다. 선택은 이 브라우저에 기억하며 카드 파일의 순서는 바꾸지 않습니다.

평가를 잘못 눌렀다면 복습 화면의 **방금 평가 고치기** 또는 카드 목록에서 복습한 카드 옆의 **평가 고치기**(미리 보기 아래쪽과 같은 화면)에서 다른 답을 고릅니다. 마지막 복습 한 건만 고칠 수 있습니다. 그 복습을 저장된 기록으로 되돌린 뒤 원래 복습한 시각에 새 답을 적용하므로 처음부터 그 답을 누른 것과 같은 일정이 됩니다. 기록에는 처음 누른 답(`correctedFrom`)과 고친 시각이 남습니다.

**이어서 연습**은 자유 연습에서 마지막으로 본 카드부터 다시 시작합니다. 위치는 묶음마다 이 브라우저에 기억하며, 끝까지 보면 처음으로 돌아갑니다. 기억해 둔 위치가 없으면 한 번도 복습하지 않은 첫 카드부터 시작합니다. 페이지를 열면 항상 ‘예정된 복습’으로 시작합니다. 세 방식 모두 정답 확인 뒤 평가 버튼이 나옵니다. 자유 연습과 마찬가지로 평가는 선택입니다.

**자유 연습**은 복습 날짜와 무관하게 선택한 묶음 전체를 앞뒤로 넘겨보는 기능입니다. 정답을 확인하면 다른 방식과 똑같이 평가할 수 있고, 평가하면 그 시각을 기준으로 기록과 다음 날짜가 저장됩니다. 평가하지 않고 넘기면 아무것도 바뀌지 않습니다. 기초 단어는 보관함의 기존 순서로 1–100, 101–200처럼 표시하며, 마지막 묶음에는 남은 카드가 들어갑니다. 카드 목록과 복습 화면의 선택은 함께 바뀌고 이 브라우저에 기억합니다. 카드 자체의 덱 이름·ID는 바꾸지 않습니다.

## 저장되는 파일

```text
SayMore/카드/
  library.json          카드 내용 + 다음 복습 날짜 + FSRS 상태 + 전체 복습 이력
  library.backup.json   직전의 정상 저장본
  notes/<카드 ID>.md    옵시디언에서 읽는 카드·일정·최근 복습 기록
  media/<파일 ID>.*     사진과 MP3
```

위 구조는 로컬 폴더 저장 기준입니다. Dropbox에서는 앱 전용 폴더의 `cards/library.json`(전체 스냅샷)과 `cards/journal.json`(스냅샷 이후 바뀐 카드)을 합친 것이 정본입니다. 답은 작은 `journal.json`에만 쓰고, 바뀐 카드가 80장을 넘으면 `library.json`에 합쳐 다시 씁니다. 두 기기에서 서로 모르게 달라진 카드는 버리지 않고 `journal.json`의 `conflicts`에 남깁니다. 스냅샷의 이전 저장본은 주 1회 `cards/backups`에 남습니다. Safari·모바일에서도 Dropbox 저장을 사용할 수 있습니다. 브라우저에는 연결 정보와 인증 정보가 남으며 카드의 정본과 전체 복습 이력은 선택한 저장소에서 읽습니다. 로컬 폴더 권한이 만료되면 **이전 폴더 연결** 또는 **폴더 연결**을 누르세요.

카드 내용은 웹 화면에서 수정합니다. Markdown의 생성 영역을 직접 수정한 내용은 웹으로 가져오지 않습니다. 생성 영역 바깥의 **추가 메모**는 보존합니다. 파일명은 단어를 바꿔도 같은 노트를 유지하도록 고유 ID를 사용합니다. 옵시디언에서는 노트 제목·본문의 단어로 찾을 수 있습니다.

카드·복습 기록이 저장된 뒤 Markdown 내보내기만 실패하면 이를 구분해 알리고 **옵시디언 노트 다시 저장**으로 복구할 수 있습니다. 이 동작은 복습 횟수를 늘리지 않습니다. 기본 저장 파일이 손상되면 덮어쓰지 않고 중단합니다. 복구 시 원본을 별도로 보관하고 `library.backup.json`을 확인하세요. 직전 저장본은 장기 백업을 대체하지 않습니다.

사진과 음성은 UUID 이름으로 보관하며 기존 첨부파일을 덮어쓰거나 자동 삭제하지 않습니다. 여러 탭의 쓰기는 Web Locks와 exclusive writer로 직렬화합니다. 파일이 외부에서 바뀌면 저장을 거절하므로 **저장된 내용 다시 읽기** 후 다시 시도합니다. 별도 브라우저나 외부 앱에서 같은 `library.json`을 동시에 편집하지 않습니다.

## 학습 방식

ts-fsrs **5.4.2**, **FSRS-6**, desired retention **0.9**, fuzz off를 사용하며 분 단위 학습 단계는 끕니다. **어려움·알맞음·쉬움**은 라이브러리의 장기 스케줄러로 일 단위 간격을 계산합니다. 새 카드의 첫 평가는 각각 2일·3일·8일이며 이후에는 기억 상태에 따라 달라집니다.

**모름**은 SayMore의 별도 정책으로, FSRS의 실패 평가로 기억 상태를 갱신하고 다음 정기 복습을 24시간 후로 정합니다. 그 전에는 **모름 다시 보기**에서 자발적으로 재도전할 수 있습니다. 조기 평가는 이 모드의 모름 카드에만 허용하며 실제 평가 시각과 결과를 기록합니다. 이 설정은 Fluent Forever의 공식 고정 간격표를 복제한 것이 아닙니다. [Anki의 학습 단계 안내](https://docs.ankiweb.net/manual/deck-options#learning-and-relearning-steps)도 같은 날의 학습 단계를 최소화하는 방향을 설명합니다.

이전 1분·10분 설정의 보관함은 설정만 호환 처리합니다. 카드 ID·이미 예약된 날짜·복습 횟수·과거 기록은 바꾸지 않으며 새 평가부터 새 정책을 적용합니다. 읽기만으로 원본 파일을 다시 쓰지 않고, 다음 저장 시 이전 정본을 백업한 뒤 새 설정을 함께 저장합니다. 모름 목록은 마지막 평가가 1인 카드에서 계산하므로 다른 기기에서도 이어집니다.

카드 수정·미리 보기는 복습 기록을 바꾸지 않습니다. 이 단어장은 Anki/AnkiWeb과 별개이며 기존 Anki 덱을 가져오거나 동기화하지 않습니다. 예전 coffee 예시는 별도의 폴더와 간격을 그대로 유지합니다.

소스는 `model.mjs`(검증·일정·노트), `storage.mjs`(로컬 파일·백업·권한), `dropbox-store.mjs`(Dropbox 저장), `view.mjs`(카드 표시), `app.mjs`(입력·목록·복습)로 나뉩니다. 브라우저에서 외부 실행 코드를 가져오지 않고 `vendor`의 고정 버전을 사용합니다. Dropbox를 연결하면 카드와 첨부파일, 복습 기록을 해당 계정의 앱 전용 폴더로 전송합니다.

## 검증

저장소 루트에서 실행합니다. Python은 Playwright와 Chromium이 설치된 환경을 사용합니다.

```sh
node --test tests/cards-model.test.mjs
python3 -m http.server 6390 --bind 127.0.0.1 --directory static
# 다른 터미널
python3 tests/cards_storage.py http://127.0.0.1:6390
python3 tests/cards_browser.py http://127.0.0.1:6390 /tmp/saymore-cards-qa
sh scripts/check
```

저장 검사는 실제 Chromium 파일 핸들을 사용하지만 선택기는 격리된 OPFS 폴더로 대체합니다. 사용자의 실제 보관함과 macOS 폴더 선택 창은 자동 테스트가 만지지 않습니다.

## 빈 이미지 보완

카드 묶음의 ‘빈 이미지·녹음 채우기’는 `images.json`과 첨부파일이 들어 있는 전용 묶음을 받습니다. `saymore-image-patch` 버전 1의 각 항목은 기존 카드 ID·정답·이미지 경로·출처를 지정합니다. ID와 정답이 일치하고 이미지가 비어 있는 카드에만 적용하며, 현재 이미지가 있는 카드는 건너뜁니다. 복습 일정과 전체 이력은 현재 보관함에서 유지하고 기존 백업·충돌 검사로 저장합니다.

같은 버튼이 녹음 묶음도 받습니다. `audio.json`(`saymore-audio-patch` 버전 1, 항목은 `audio` 목록)과 MP3 파일이 들어 있으면 녹음이 비어 있는 카드에만 붙입니다. 합성 음성 문장(`speech`)은 그대로 두므로 카드 뒷면에 사람 녹음과 기기 합성 음성 버튼이 함께 나옵니다.

글 수정 묶음(`text.json`, `saymore-text-patch` 버전 1, 항목은 `cards` 목록)도 같은 버튼으로 받습니다. 각 항목은 카드 ID·정답과 함께 바꿀 칸(`front`·`ipa`·`sentence`·`memory`)의 현재 글(`was`)과 새 글(`set`)을 적습니다. 현재 글이 `was`와 다르면 그사이 고친 카드로 보고 전체를 저장하지 않습니다. 복습 일정과 이력은 그대로입니다.
