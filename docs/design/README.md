# Say More 디자인 초안 보관

사이트에는 올라가지 않는, 디자인을 고를 때 만든 자료입니다. HTML 파일은 브라우저로 바로 열 수 있습니다.

| 파일 | 내용 |
|---|---|
| `saymore-drafts-100.html` | 색·글꼴·모양 초안 100개. "추천만" 단추로 추천안 12개만 볼 수 있습니다. |
| `recommended.json` | 추천안 12개와 사이트에 적용한 3개(003 흑백 미니멀, 055 드라큘라, 067 팝)의 색·글꼴·모양 값. |
| `drafts-100/` | 위 갤러리의 원본. `python3 build.py` 로 다시 만듭니다. |
| `saymore-layouts-20.html` | 메뉴 위치와 상자 배치 초안 20개 (맥·아이폰 화면, 세 테마 전환). |

사이트에 실제로 쓰는 테마 값은 `static/saymore/skin.css` 에 있습니다.
